# Paradise Code

## Platform
web

## Users
Developers evaluating an independent macOS editor and the creator sharing it publicly.

## Product Purpose
A local, familiar Code – OSS development workflow inside a Tauri 2 desktop shell.

## Capabilities and Constraints
Apple Silicon macOS preview. Full upstream workbench plus a bundled Node backend, terminal, Git, web languages and compatible Open VSX extensions. No proven memory advantage over VS Code. No notarization, Microsoft Marketplace, cloud sync, or included remote development. Build data stays on the owner's external SSD. Public downloads use isolated app data.

## Brand Commitments
Paradise Code. Creator: https://paradisecode.ir. Website: https://ide.paradisecode.ir. User rejected the previous bracket-P icon and cream landing page, and delegated visual and implementation decisions. English initial UI. Preserve VS Code interaction conventions inside the app.

## Evidence on Hand
Actual built macOS app and validation records in validation/. Do not invent adoption, performance wins, or production certification.
