From an idea to an installed tool.

  1. CreateChoose a name and folder. Paradise writes the manifest and a working command.
  2. Make it yoursUse the small Paradise SDK for commands, status items and saved state. The full VS Code API is there when you need it.
  3. Package & installOne command produces a standard VSIX and installs it. First use downloads the packaging tool.

Paradise’s catalog is curated from the public repository. To share an extension, submit its manifest and VSIX through a pull request; packages are reviewed before catalog inclusion.

Existing tools are welcome too.

Extensions execute local code with your user’s permissions. Install from authors you trust. VSIX import remains available in the Extensions view.
