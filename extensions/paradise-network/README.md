# Paradise Network

Open **Paradise: Network Usage** and select **Start recording**. A per-user macOS LaunchAgent reads physical interface counters, including when the editor is closed. Stop recording in the panel or run **Paradise: Stop Network Recording**. Removing the extension through the Paradise Hub stops its service first.

Choose dates to compare recorded received and sent bytes, or export minute samples to CSV. Data stays in the extension's local storage folder. History starts with recording; sleep, unavailable storage and disabled recording are gaps. Wi-Fi and Ethernet bytes include local traffic and VPN transport. Virtual interfaces are excluded to prevent double counting. These values are neither per-app internet usage nor an ISP billing meter. The extension currently requires macOS.
