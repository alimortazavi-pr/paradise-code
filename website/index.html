A little clarity
before you commit.

How close is this to VS Code?

Paradise Code is built on Code – OSS 1.140.0. It retains the upstream workbench, standard .vscode files, and extension APIs. It is independent of Microsoft; Marketplace and proprietary services are not bundled. Compatibility depends on the extension.

Can I use it for my everyday work?

This is a public preview, with local web development as its tested path. Core workflows have acceptance tests, but it is not a production certification. Keep backups and check the published limitations before relying on an extension or workflow.

What’s included, and what isn’t?

Editing, local Git, terminal, Tasks, Node debugging, web IntelliSense, compatible Open VSX extensions, and signed updates. AI features, Remote SSH, Containers, and cloud settings sync are outside this release.

Does it need the internet to run?

No internet server is needed for the editor or its local backend. Downloads, extension installation, updates, and your own project’s network dependencies still need a connection.

Who’s behind Paradise Code?

Built by Paradise Code, on the work of the Code – OSS, Tauri, Rust, Node.js, and WebKit communities. The source is public under MIT; bundled components keep their own licenses.
