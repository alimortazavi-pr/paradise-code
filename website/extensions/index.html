Paradise Network

macOS · Version 0.1.0

See live received and sent rates across your Mac’s physical network interfaces. Compare recorded usage across dates and export minute samples to CSV. A local background service can keep recording while the editor is closed.

Included in the Paradise catalog. In Paradise Code 0.4.2, run Paradise: Extension Hub, install Paradise Network, then choose Start recording.

Make your own in three steps.

  1. Run Paradise: Create Extension. Choose a name and a folder.
  2. Edit extension.cjs. The small SDK provides commands, status items, notifications and stored state. Use the full Code – OSS extension API for deeper tools.
  3. Run Paradise: Package and Install Extension. Paradise uses its bundled Node and npm to produce a standard VSIX and install it. First use downloads the official packaging tool; it is cached for later use.

Share a tool through a pull request to the Paradise repository. The catalog is curated: submitted packages are reviewed before inclusion. Open VSX and imported VSIX extensions remain supported.

Network history begins when you start recording. It includes local network traffic and VPN transport, excludes virtual interfaces to avoid duplicate counts, and does not provide per-app internet billing. Sleep, unavailable storage and stopped recording create gaps. Usage data stays on your Mac. Extensions run local code with your user’s permissions; install from authors you trust.
